## Descripcion

El proyecto consiste en el desarrollo de una landing page inspirada en la interfaz visual de ExpressVPN, utilizando HTML y CSS para replicar la estructura, los colores, la distribucion de contenido y los elementos visuales de la referencia proporcionada.

## Tecnologias utilizadas

- HTML5
- CSS3

## Objetivo

Construir una pagina web estatica con una presentacion visual clara, moderna y organizada, aplicando conceptos de maquetacion, estilos, jerarquia visual y adaptabilidad basados en el contenido del primer corte.
